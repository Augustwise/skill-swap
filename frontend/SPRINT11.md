# Sprint 11 — Наскрізне (E2E) та нефункціональне тестування клієнтської частини

Цей документ описує набір наскрізних браузерних тестів Playwright для клієнтської частини **SkillSwap** (`frontend/`), розроблений для перевірки виконання всіх пов'язаних функціональних (`FR-01`–`FR-15`, `UC-01`–`UC-06`) та нефункціональних (`NFR-01`–`NFR-12`) вимог специфікації.

## Архітектура тестового стенда

- **Реальний production-клієнт Next.js 16**: тести запускаються командою `npm run test:browser` проти зібраного сервера `next start --hostname 127.0.0.1 --port 3100`.
- **Ізольований багатокористувацький стенд (`tests/browser/mvp-fixture.mjs`)**: кожен тест створює власний стан (`createMvpWorld`) і підключає один або кілька незалежних `BrowserContext` (студенти, непідтверджений акаунт, сторонній користувач, адміністратор). Перехоплення `**/api/v1/**` та локальної поштової скриньки Mailpit (`http://127.0.0.1:8025/**`) відтворює контракт `backend/docs/openapi.yaml` (сесійні `HttpOnly` cookies `skillswap_session`, перевірка `X-CSRF-Token`, одноразові токени пошти й скидання пароля, rate-limit `429`, перевірка накладання інтервалів занять, двосторонні підтвердження, модерація та знеособлення видаленого акаунта) **без звернень до віддаленої чи спільної бази PostgreSQL**.
- **Автовибір браузера (`playwright.config.mjs`)**: використовується `PLAYWRIGHT_CHANNEL` (наприклад, `chrome` або `msedge`), системний Chrome/Edge або встановлений Playwright Chromium.

## Команди запуску

З каталогу `frontend/`:

```bash
npm run build                  # production-збірка Next.js + перевірка типів TypeScript
npm test                       # модульні тести клієнтської логіки (node:test)
npm run test:browser           # повний набір браузерних E2E та NFR тестів Playwright
npx playwright test tests/browser/mvp-journey.spec.mjs   # окремий наскрізний сценарій MVP
npx playwright test tests/browser/nfr.spec.mjs           # окремий набір нефункціональних тестів
npm run lint && npm run format:check
```

Для запуску в іншому браузері (кросбраузерна перевірка `NFR-09`):

```powershell
$env:PLAYWRIGHT_CHANNEL="msedge"; npx playwright test tests/browser/mvp-journey.spec.mjs tests/browser/nfr.spec.mjs
```
