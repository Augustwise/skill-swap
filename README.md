# Skill Swap

## Getting Started

### Requirements

- Node.js 18 or later
- npm

### Installation

1. Open a terminal in the project root.
2. Go to the frontend directory and install the dependencies:

   ```bash
   cd frontend
   npm install
   ```

### Run the project

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production build

To create and run a production build:

```bash
npm run build
npm start
```
